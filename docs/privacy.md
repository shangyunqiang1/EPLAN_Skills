# 数据与隐私

本地 `eplan` MCP 通过 EPLAN Remote Client 与本机 EPLAN 交互，可以读取或修改授权范围内的工程数据，也可能按请求执行脚本、生成导出文件或写入操作日志。日志默认位于 `%LOCALAPPDATA%\EPLAN_Skills\logs`，或环境变量 `EPLAN_SKILLS_DATA_DIR` 指定的数据目录下的 `logs`；其中可能包含项目路径等敏感数据。日志和导出文件应按本机项目数据管理。

启动器在同一数据目录的 `runtime/` 下创建版本化服务器副本，上游生成的临时 C# 与执行结果位于该副本中，可能包含工程数据。插件更新不会自动清除旧 runtime 或日志，需要清理时先停止相关 MCP 进程并按本机数据策略处理。

`eplan-rag`、`eplan-wiki-2027` 和 `eecpro-rag` 是 Canary E-cad 运营的远程文档服务。使用它们时，客户端发送的查询文本会到达对应第三方服务。请勿在未获允许时向查询中加入工程机密、个人信息或凭据；第三方的数据保留和服务政策以其自身说明为准。

可选符号搜索先在本机从所选图像生成向量，再将该向量发送到上游符号检索服务以获取匹配项。它默认不启用；启用前应确认图像及衍生向量可以发送到该服务。首次使用可能从模型提供方下载模型，Python 依赖安装也需要访问相应包源。

本仓库不包含本机 EPLAN DLL、用户工程、凭据或 EPLAN 专有文档索引。上游文档搜索索引的内容权利属于其各自所有者；上游代码的 MIT 许可证不授予其文档内容的再分发权。
